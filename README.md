# Название и цель
Проект демонстрирует правильную организацию файлов в GitHub-репозитории для задач анализа данных. Цель - отработать загрузку файлов, создание папок и оформление документации (README.md) в соответствии с требованиями.
# Состав файлов
- `notebooks/lr01_runtime_order_фамилия.ipynb` — основной notebook с кодом и Markdown‑пояснениями;
- `data/sample_text.txt` — пример текстового файла;
- `data/mini_corpus.tsv` — пример табличных данных;
- `docs/version_log.md` — журнал изменений проекта.

# Как открыть
1. Скопируйте ссылку на репозиторий.
2. Откройте файл `notebooks/lr01_runtime_order_фамилия.ipynb` в Jupyter Notebook или Google Colab.
3. Выполните `Kernel → Restart & Run All` для проверки воспроизводимости.


# Проверка
Проект работает корректно, если:
- все ячейки notebook выполняются без ошибок;
- вывод ячеек соответствует ожиданиям;
- данные из `data/` загружаются корректно.

# Ограничения
- Проект не использует внешние библиотеки, кроме стандартных.
- Данные безопасны для публикации (нет персональных данных).
- Для запуска требуется среда Python с поддержкой Jupyter.
